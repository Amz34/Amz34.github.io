Architectural Guarantees

Designed from first principles to prevent detonation and hallucination during autonomous agent runs.

🛡️

Strictly Read-Only

Only verified analysis binaries are invoked (readelf, objdump, radare2, jadx, Ghidra). Samples are strictly never executed in memory or disk.

🎯

Zero Hallucination

Missing system backends explicitly return {"tool_missing": "..."}. Rekit never fabricates a metric, string, or disassembly result.

⚡

Machine-Readable

Every subcommand natively outputs clean, schema-consistent JSON with --json, allowing LLM agent toolchains to parse payloads seamlessly.

⏱️

Bounded Execution

All child subprocesses enforce hard timeout limits and respect REKIT_MAX_BYTES memory boundaries to protect system availability.

13 Specialized Subcommands

Modular analysis engines switchable between standalone terminal execution and MCP server calls.

Quickstart & MCP Configuration

Run directly from stdlib or mount as a zero-trust MCP server for Claude, Cursor, and autonomous agents.

# 1. Clone repository (stdlib CLI, no complex pip dependencies)
$ git clone https://github.com/Amz34/rekit.git && cd rekit
 
# 2. Triage binary with structured JSON output
$ python3 rekit.py triage /bin/ls --json
 
# 3. Extract high-entropy IOCs and credentials from firmware / bundles
$ python3 rekit.py iocs ./firmware_extracted/sys.img
 
# 4. Attach as Model Context Protocol (MCP) server in claude_desktop_config.json
{
  "mcpServers": {
    "rekit": {
      "command": "/usr/bin/python3",
      "args": ["/path/to/rekit/mcp_server.py"]
    }
  }
}
