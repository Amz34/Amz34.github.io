    Rekit Documentation¶

    rekit gives a terminal — and any Model Context Protocol (MCP) compatible AI agent — a single safe, deterministic front-end for static binary analysis: file triage, strings, IOC extraction, disassembly, APK/DEX, firmware images, JS bundles, PCAPs and headless Ghidra decompilation. It never executes a sample in memory or on disk, and it never invents a result.

    Rekit ships as a lightweight, zero-dependency CLI and high-integrity MCP server:

    Interface Entrypoint Install / Run Guarantees
    CLI (Python) rekit.py python3 rekit.py --help Pure stdlib, zero-execution sandbox
    MCP Server mcp_server.py python3 mcp_server.py Model Context Protocol (JSON-RPC)

    Key Features¶

    • Strictly Read-Only — only verified analysis binaries (readelf, objdump, radare2, jadx, tshark, Ghidra headless) are invoked. Samples are never executed.
    • Nothing Faked — missing system backends explicitly return {"tool_missing": "..."}. Rekit never hallucinates or guesses.
    • Machine-Readable Output — every subcommand accepts --json for direct agent and toolchain ingestion.
    • Bounded Execution — every subprocess enforces hard timeouts and bounded input size caps via REKIT_MAX_BYTES.

    Quick start in 30 seconds¶

    import json
import subprocess

# Direct triage of binary with clean JSON output
res = subprocess.check_output(["python3", "rekit.py", "triage", "/bin/ls", "--json"])
data = json.loads(res)
print(f"SHA256: {data['sha256']} | Kind: {data['kind']}")

    Command line (Python)¶

    # Clone and run stdlib CLI
git clone https://github.com/Amz34/rekit.git && cd rekit

# Fast triage: hashes, file format, sections, entropy, packer detection
python3 rekit.py triage /bin/ls --json

# High-entropy strings and indicators of compromise (IOCs)
python3 rekit.py iocs ./firmware_extracted/sys.img

# Function disassembly & headless Ghidra decompilation to C
python3 rekit.py disasm /bin/ls --func main
python3 rekit.py ghidra /bin/ls --out tiny.decompiled.c

    MCP Server Integration¶

    Connect rekit as an autonomous static analysis tool for Claude Desktop, Cursor, or sovereign agent runtimes:

    {
  "mcpServers": {
    "rekit": {
      "command": "/usr/bin/python3",
      "args": ["/home/ubuntu/projects/rekit-public/mcp_server.py"]
    }
  }
}
